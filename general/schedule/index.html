Master Schedule 2026–2027

ℹ️ About this report — what each tab does
🗓️ Schedule
☀️ Daily — the week at a glance: which class codes run in each bell slot, per day. Hover a class pill to see its teacher. Start here for quick questions.
📋 Detailed — the full grade-section grid with exact labels and teacher tooltips. Use the day tabs to focus one day or expand the whole week.
🛠️ Filter rail — everything left of the grids filters what you see, top to bottom: Periods (the transit line — green stop = shown, red = hidden; # and Time cells in the grid toggle too), Grades (Elem · Mid/Up · Type columns), Courses by Teacher, and Courses by Colors — the last two searchable by name, code, or hex. Every exclusion is spelled out in red above the grid, and 🧹 restores everything.
🏋️‍♀️ Teacher Load — beneath the grids: periods occupied per teacher per day — one count per bell slot, however many codes or sections share it. Off-periods are not counted.
⬅️ Timeline ➡️ — the same filtered schedule flattened into chronological rows: day, time range, the class codes running, and how many. Day tints match the Daily grid.
📆 Calendar
The dual-calendar (Gregorian · Hijri · HLA · HISD · Δ) now lives at School Calendar.
🚨 Alerts — appears under this panel whenever the data contains scheduling conflicts (a teacher booked in two classes at once); "Review conflicts" jumps straight to the affected entries and the 🧩 Move Recommender.
⚙️ ADMIN — dataset counts at a glance (hover any card for a preview), the ⚙️ Control panel with the maintainer tools — ✏️ edit mode (drag-and-drop rescheduling and teacher assignment, applied changes are written back and logged with time and method), ⚠️ conflicts, ⟳ refresh, 📁 data folder, and the refresh/edit history — plus the color-and-teacher decoder and the raw source rows behind every number.
